## 解题过程

### 0x01 侦察页面

打开环境，页面不停弹出对话框："来找找吧"、"flag 就在这里"……点掉一个又弹一个，仿佛在嘲讽。页面本体没有任何可交互的内容。

关键认知：**`alert()` 是 JS 的运行时行为，只存在于浏览器的执行阶段；服务器返回的源码从始至终躺在那里，一秒都没变过。** 弹窗只是干扰项，不需要跟它纠缠。

### 0x02 绕过弹窗看源码

三种方式任选其一：

| 方式 | 操作 |
|------|------|
| 阻止对话框 | 触发一次弹窗后，Chrome 弹窗左下角勾选「阻止此页面创建更多对话框」，之后 F12 看 Elements |
| **直接看源码** | `Ctrl + U` 查看源代码，JS 弹窗完全不影响，**最快** |
| 抓包 | Burp / F12 Network 面板看响应体原文，最干净 |

在源码末尾的 HTML 注释里发现一串可疑内容：

```html
<!-- &#75;&#69;&#89;&#123;&#74;&#50;&#115;&#97;&#52;&#50;&#97;&#104;&#74;&#75;&#45;&#72;&#83;&#49;&#49;&#73;&#73;&#73;&#125; -->
```

（数字每次开环境可能不同，以自己页面为准。）

### 0x03 解码 HTML 实体

`&#数字;` 是 **HTML 实体编码（十进制字符引用）**，每个数字是一个 ASCII 码。三种解码姿势：

**姿势一：CyberChef**（推荐，收藏备用）——粘贴整串，Recipe 选 `From Decimal`，分隔符填 `Auto`，直接出明文。

**姿势二：Python**

```python
s = "&#75;&#69;&#89;&#123;&#74;&#50;&#115;&#97;&#52;&#50;&#97;&#104;&#74;&#75;&#45;&#72;&#83;&#49;&#49;&#73;&#73;&#73;&#125;"
print(''.join(chr(int(x)) for x in s.replace('&#', '').split(';') if x))
# 也可以直接一行：import html; print(html.unescape(s))
```

**姿势三：浏览器控制台**

```javascript
"&#75;&#69;&#89;&#123;...".replaceAll("&#", "").split(";")
    .map(s => String.fromCharCode(parseInt(s))).join("")
```

解码得到 `KEY{***}` 形式的 flag，回平台提交，+10 分。

## 原理分析

### 弹窗为什么拦不住我们

`alert()` 属于 JS 在浏览器里的运行时行为，而 `Ctrl + U` 展示的是服务器返回的 **HTTP 响应原文**——在解析和执行之前的原始字节流。干扰发生在"执行层"，信息躺在"源码层"，两不相干。这与「滑稽」一题"渲染层 vs 源码层"的思路一脉相承：**页面怎么表现是一回事，服务器发了什么另一回事**。

### HTML 实体编码

HTML 实体（Character Reference）是 HTML 规范中的转义机制，用于安全表示保留字符（`<` `>` `&`）与不可见字符，浏览器解析文档时会自动将其还原为真实字符：

- `&#75;` —— 十进制形式，表示 ASCII 75，即字母 `K`
- `&#x4B;` —— 十六进制形式，同样表示 `K`

本题把它当成了**轻度混淆**：源码里看不到明文 flag，仿佛"藏起来了"。但 View Source / 抓包拿到的是原始字符流，`html.unescape()` 或 CyberChef 一步还原——**编码 ≠ 加密**，没有密钥的变换对攻击者只是多一步操作而已。

### 渗透视角启示

- 遇到 JS 干扰（弹窗、强制跳转、禁用右键），一律不影响查看源码或抓包
- 看到源码里的编码串（`&#..;` / `%xx` / Base64 / `\uXXXX`）先解码再判断价值，这是 CTF 前端题的高频套路

## 复盘

- 解题路径：弹窗干扰 → `Ctrl + U` 看源码 → 注释中发现 HTML 实体编码 → CyberChef 解码 → 提交
- **知识沉淀**：
  - `&#N;`（十进制）/ `&#xN;`（十六进制）= HTML 实体编码的识别特征
  - Python `html.unescape()` 一行解所有 HTML 实体，建议记住
  - CyberChef 正式入列常用工具
- 陷阱提醒：flag 前缀可能是 `KEY{}` / `CTF{}` / `flag{}`，按平台提示格式提交；密文数字每次开环境可能变化，别直接抄别人的明文
- 编码家族延伸（后续题目会逐一遇到）：HTML 实体 → URL 编码 → Base64 → Unicode 转义 → JSFuck，本题是这条链的第一站
- 同类题识别：**页面有干扰 + 源码有编码串 = 信息泄露 + 编码还原的组合拳**
