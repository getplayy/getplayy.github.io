- **分值**：10 分（入门）
- **考察点**：摩斯电码解码 + 解码工具的分隔符参数匹配

> 个人学习记录，flag 已打码，请自行做题获取。

## 题目描述

题目名 `/.-`，密文是一长串由 `.`（点）、`-`（划）、空格、`/` 组成的文本。

## 解题过程

### 0x01 识别：题目名就是答案

`/.-` 只由点、划、分隔符组成——**摩斯电码**的指纹特征。开环境看到密文确认无误：

```text
..... / ... / -.-. ----- ...（示例，以自己页面为准）
```

### 0x02 CyberChef 解码——第一个坑：Output 是空的

打开 [CyberChef](https://cyberchef.org/)，搜索 `Morse` → 拖入 `From Morse Code` → 密文粘进 Input——

**Output 一片空白。** 操作没拖错、密文也粘了，为什么？

### 0x03 分析：分隔符不匹配

仔细看 Recipe 里 `From Morse Code` 的两个参数：

| 参数 | 当前值 | 密文实际情况 |
|------|--------|-------------|
| Letter delimiter（字母分隔） | `Space` 空格 | ✅ 匹配（字母间确实是空格）|
| **Word delimiter（单词分隔）** | **`Line feed` 换行符** | ❌ **不匹配（密文里单词分隔是 `/`）** |

CyberChef 找不到换行符，整段密文的解析直接失败 → Output 空。

### 0x04 第二个坑：参数删不掉

想把 `Line feed` 改成 `/`——**退格键删不动它**。

原因：`Line feed` 在参数框里不是普通文本，而是一个**整体的特殊字符 token**（换行符），不能像普通字符串那样编辑。

### 0x05 最终解法：改密文，不改参数

换思路——**与其改工具参数，不如改数据本身**：

1. 密文粘进**记事本**
2. `Ctrl + H` 打开替换：
   - 查找内容：`/`
   - 替换为：**一个空格**
   - 点「全部替换」
3. 替换后的密文重新粘进 CyberChef 的 Input（**参数保持默认不动**）
4. Output 立刻出明文 ✅

```text
FLAGD3FCBF17F9399504（示例格式，以自己解出的为准）
```

### 0x06 拿分

注意本题 flag **格式特殊**：`FLAG` 前缀大写、**没有大括号**，直接跟十六进制串——按原样提交，+10 分。

*（此处配一张 CyberChef 解出明文的截图）*

## 原理分析

### 摩斯电码的完整规则

摩斯用长短两种信号编码字符，**字符集只有点、划、和两种分隔符**：

- 字母内部：`-` 和 `.` 直接相连，如 `F` = `..-.`
- **字母之间**：空格分隔
- **单词之间**：`/`（或换行、多空格，约定不唯一）

常用字母分到短码（`E`=`.`、`T`=`-`），是**变长编码 + 词频优化**的鼻祖，哈夫曼编码（1952）在思想上直系继承。

### 通用教训：参数与数据格式必须匹配

这题真正的考点不是"认识摩斯"（太基础），而是**解码工程中的格式匹配意识**：

> Output 为空 ≠ 工具坏了 ≠ 密文错了，先检查**分隔符约定**。

所有编解码工具（CyberChef、各类在线工具）处理摩斯、CSV、Base64 变体时都有分隔符参数，**数据格式和参数对不上是新手最常见的"无声失败"**——没有报错，只是空结果。

### 改数据的思路

改不动工具参数时，**反过来改数据去适配工具**：`/` 换成空格后，"单词分隔"信息丢失了——但 flag 是一串连续字符，根本不需要单词边界，**丢掉不影响结果的信息**正是解题的常用取舍。

## 复盘

- 解题路径：识别摩斯 → CyberChef 空 Output → 发现 Word delimiter 不匹配 → 参数删不掉 → 记事本替换 `/` 为空格 → 默认参数解出，全程约 10 分钟（含排坑）
- **踩坑记录**（本文最值钱的部分）：
  1. Output 空白时先查参数，尤其分隔符
  2. CyberChef 参数框里的 `Line feed` 是特殊字符 token，退格删不掉——别硬刚，改数据更省事
- **flag 格式陷阱**：本题是 `FLAG` + 十六进制、无大括号——CTF 平台格式不统一，提交前先看题目描述要求
- CyberChef 的 URL 直达技巧：`https://cyberchef.org/#recipe=From_Morse_Code('Space','/')` 用 URL 参数直接配好 recipe，跳过界面操作
- 知识链：编码四连做的第三站——栅栏（置换）→ **摩斯（信号编码 + 格式匹配）** → Ook/Brainfuck（玩具语言）
