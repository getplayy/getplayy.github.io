## 题目描述

题目名「ok」，密文由 `Ook.`、`Ook?`、`Ook!` 三种片段循环组成，一眼望不到头：

```text
Ook. Ook? Ook. Ook. Ook. Ook! Ook? Ook.（示例，以自己页面为准）
```

## 解题过程

### 0x01 识别：满屏 Ook 就是 Ook! 语言

密文只由三种 token 组成——`Ook.`（陈述）、`Ook?`（疑问）、`Ook!`（感叹）。这是 **Ook! 语言**，Brainfuck 的"猩猩版"（Ook 是猩猩叫声，梗出自《碟形世界》）。

### 0x02 CyberChef 解码——连环踩坑

理论路径：CyberChef → 搜索 `Brainfuck` → 拖入 `To/From Brainfuck` → 参数从 `Standard` 改成 `Ook` → 出明文。

实际操作一路磕绊：

**坑 1：搜索 "Brainfuck" 没有结果** —— CyberChef 是 github.io 域名，国内访问时快时慢，页面没加载完时左侧列表是空的，搜索自然没反应（等加载完再搜就好了）。

**坑 2：搜出来的操作叫 `To Brainfuck`** —— 和我预期的 `To/From Brainfuck` 名字对不上，第一眼以为搜错了。其实是同一个操作，版本不同显示名略有差异。

**坑 3：拖进 Recipe 后参数下拉框不见了** —— 屏幕窗口不够宽，操作框里的 `Standard` 下拉菜单被挤出可视区域，翻半天找不到改 `Ook` 的地方。

### 0x03 换工具：splitbrain 一发入魂

与其继续和界面搏斗，**直接换专用工具**：

1. 打开 **[splitbrain.org/services/ook](https://www.splitbrain.org/services/ook)**
2. 密文整段粘进大文本框
3. 点 **`Ook! to Text`** 按钮（注意方向：**to Text = 解码**）
4. 结果直接显示 ✅

```text
flag{***}
```


### 0x04 拿分

复制提交，+10 分。

## 原理分析

### Ook! 是 Brainfuck 换了层皮

Ook! 与 Brainfuck **指令一一对应**，只是写法不同：

| Ook! | Brainfuck | 含义 |
|------|-----------|------|
| `Ook. Ook?` | `>` | 指针右移 |
| `Ook? Ook.` | `<` | 指针左移 |
| `Ook. Ook.` | `+` | 当前格 +1 |
| `Ook! Ook!` | `-` | 当前格 -1 |
| `Ook. Ook!` | `.` | 输出字符 |
| `Ook! Ook.` | `,` | 读入字符 |
| `Ook! Ook?` | `[` | 循环开始 |
| `Ook? Ook!` | `]` | 循环结束 |

CyberChef 里选 Ook 模式，本质是先做 token 替换再跑 Brainfuck 解释器。

### 这类语言叫 esolang（深奥语言）

**图灵完备但专为娱乐设计**，绝无生产用途。共同点：指令集极小、写出来像乱码但严格可执行。CTF 里的定位是**识别题**——认出语言 → 找解释器 → 粘贴 → 完事，考的是知识面广度而非深度。

### 通用教训：工具链要有 Plan B

本题最大的收获不是 Ook! 本身，而是**工具切换意识**：

| 场景 | 首选 | Plan B |
|------|------|--------|
| 通用编解码 | CyberChef | [cyberchef.org 镜像域名](https://cyberchef.org/)、ctf 在线工具站 |
| Ook!/Brainfuck | CyberChef（参数选 Ook）| **splitbrain.org/services/ook**（界面极简，粘贴点按钮即出）|
| CyberChef 加载慢 | 等待/换时段 | 用 URL 直达 `#recipe=From_Brainfuck('Ook')` 跳过界面操作 |

**卡在工具的界面问题上超过 5 分钟，就该换工具了**——解题考的是思路，不是和某个网站的 UI 死磕。

## 复盘

- 解题路径：识别 Ook! → CyberChef 三连坑（搜索空/名字差异/参数被挤没）→ 换 splitbrain → `Ook! to Text` 一键出明文
- **按钮方向的规律**：splitbrain 的按钮命名是"源 to 目标"——**解码选箭头指向 Text 的那个**（`Ook! to Text`、`Brainfuck to Text`），加密选反的
- **踩坑记录**：
  1. CyberChef 搜索无结果时先确认页面加载完没有（左侧列表是空的=还没加载好）
  2. 窗口太窄时操作参数会被挤出视野——**最大化窗口**或**向下滚动 Recipe 区**
  3. 同一个功能在不同工具/版本里叫法不同，认**关键词**（Brainfuck）而不是全名
- 知识链：编码四连的第四站（最终站）——栅栏（置换）→ 摩斯（信号+格式匹配）→ **Ook（玩具语言 + 工具切换）**，与下一题 [+-<>]（Brainfuck 本体）正好组成一对
