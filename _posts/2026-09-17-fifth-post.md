# 细节原理
- 弹窗为什么拦不住我们
alert() 属于 JS 在浏览器里的运行时行为，而 Ctrl + U 展示的是服务器返回的 HTTP 响应原文——在解析和执行之前的原始字节流。干扰发生在"执行层"，信息躺在"源码层"，两不相干。这与「滑稽」一题"渲染层 vs 源码层"的思路一脉相承：页面怎么表现是一回事，服务器发了什么另一回事。
- HTML 实体编码
HTML 实体（Character Reference）是 HTML 规范中的转义机制，用于安全表示保留字符（<>&）与不可见字符，浏览器解析文档时会自动将其还原为真实字符

# 安全概念
编码 ≠ 加密，没有密钥的变换对攻击者只是多一步操作而已
