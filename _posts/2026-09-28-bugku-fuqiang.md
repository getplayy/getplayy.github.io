## 解题过程

### 0x01 识别编码

先看字符集：整段密文翻来覆去只用了 12 个词——**富强、民主、文明、和谐、自由、平等、公正、法治、爱国、敬业、诚信、友善**，正好是社会主义核心价值观 24 个字。

字符集限定在一个固定词表内、大量重复、又不是任何常见编码——直接锁定：**社会主义核心价值观编码**（GitHub 上的娱乐编码器 [core-values-encoder](https://github.com/sym233/core-values-encoder)，国内 CTF 常客）。

### 0x02 弄懂原理（比直接丢工具重要）

翻编码器源码，链路一共三步：

1. **明文 → hex**：`"flag"` → UTF-8 → `"666C6167"`；
2. **hex → 十二进制位流**：12 个词恰好当十二进制的 12 个数字用——富强=0、民主=1、文明=2、和谐=3、自由=4、平等=5、公正=6、法治=7、爱国=8、敬业=9、诚信=10、友善=11；
3. **逐位查表拼词输出**。

麻烦在 hex 字符是 0~F（16 个值），一个词只能表示 0~11，所以：

- `0~9` → 1 个词；
- `A~F` → **2 个词**，且有两种随机等价写法（`诚信+X` 或 `友善+X`）。

这就是为什么本题密文 47 个词、**没有固定分组**——和上一题"整 6 字符一组"完全不同。

### 0x03 解码

在线工具（[SSLeye](http://ctf.ssleye.com/)、随波逐流都有现成组件）直接出结果。工具挂了就自己写，解码只需看每个词的**第一个字**：

```python
VALUES = '富强民主文明和谐自由平等公正法治爱国敬业诚信友善'

def decode(cipher):
    duo = []
    for ch in cipher:                      # 步骤1：词首字 -> 十二进制位
        idx = VALUES.find(ch)
        if idx != -1 and idx % 2 == 0:
            duo.append(idx >> 1)
    hexs, i = [], 0                        # 步骤2：十二进制 -> hex
    while i < len(duo):
        d = duo[i]
        if d < 10:
            hexs.append('%X' % d)
        elif d == 10:                      # 诚信, n-10
            i += 1; hexs.append('%X' % (duo[i] + 10))
        else:                              # 友善, n-6
            i += 1; hexs.append('%X' % (duo[i] + 6))
        i += 1
    return bytes.fromhex(''.join(hexs)).decode('utf-8')  # 步骤3：hex -> 明文

print(decode('公正公正公正诚信文明...'))    # flag{***}
```

边解边验证：开头解出 `66 6C 61 67` 正是 `flag`，方向就对。

## 原理分析

### 词表式编码："魔改 Base"家族

本质是**自造字符集 + 进制转换**。理解后一整类"奇葩编码"都是同一套路的不同皮肤：

| 编码 | 字符集特征 | 一眼识别 |
|---|---|---|
| 核心价值观编码 | 24 字价值观 | 密文全是"富强民主…" |
| 与佛论禅 | "佛曰：冥奢梵…" | 以"佛曰："开头 |
| 熊曰编码 | "熊曰：蜂蜜洞穴…" | 以"熊曰："开头 |
| 兽音译者 | 嗷呜啊~ | 全是"嗷呜啊"组合 |
| Brainfuck | `+ - < > [ ] . ,` | 符号极度受限 |

### 通用识别方法论

1. 看**字符集**——固定小集合 + 鲜明主题 → 词表类编码；
2. 在线工具批量试（随波逐流、SSLeye）；
3. 工具不认识 → **搜 GitHub 找源码读懂映射，自己写脚本**——本题完整走了一遍这条最兜底也最通用的路。

## 复盘

- 解题路径：认字符集 → 定位编码 → 读源码弄懂十二进制映射 → 解码验证，全程 10 分钟
- **别套固定分组思维**：上一题整 6 字符一组，这题 `A~F` 占两个词导致分组不固定——先入为主会直接卡死
- **抄写零容忍**：多一个"和谐"少一个"和谐"，从错的位置起全部解歪
- **渗透视角**：真实场景里的自定义协议、恶意样本通信也常用自造编码躲检测，"识别字符集 → 找映射"的套路不变
- 知识链回顾：散乱的密文（**换位置**，置换密码）→ 富强民主（**换字符集**，词表编码）——古典密码两大门类入门双璧，凑齐了
